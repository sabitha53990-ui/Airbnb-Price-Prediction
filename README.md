# Airbnb Price Prediction

## Overview
This project predicts Airbnb listing prices using Linear Regression based on features such as property type, room type, accommodates, bathrooms, cleaning fee, latitude, and longitude.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Results
The model was trained to predict Airbnb prices and showed reasonable performance. Visualizations were used to analyze feature relationships and compare actual vs predicted prices.

## Conclusion
This project demonstrates data cleaning, feature engineering, data visualization, and machine learning techniques for price prediction.
